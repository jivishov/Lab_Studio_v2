# Lab Studio Instructional Video Script

Target length: 4-6 minutes  
Target audience: teachers and students  
Recording source: production build opened in Chromium at 1280x720  
Final deliverables: `lab-studio-instructional.mp4`, `captions.vtt`, and this script

The table below is the planned storyboard. `captions.vtt` is generated by
`scripts/record-instructional-video.mjs` from the actual capture timings so it
accounts for route loading, clicks, export/import, and transcode overhead.

## Production Notes

- Record from `npm run build` plus Vite preview, not from the dev server.
- Use temporary browser overlays for captions, cursor focus, and highlights only during capture.
- Keep the MP4 silent; the text above is the companion voiceover script/transcript.
- Do not change app source code to make the recording work. Report any blocker separately.
- Do not touch `src/trials/*`.
